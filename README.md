# isaac_history_mod
Adds a clean Run History menu displaying a visual summary of your last 10 completed Binding of Isaac runs — right from the Main Menu (with REPENTOGON) or anytime during a run in Vanilla Repentance / Repentance+!

FEATURES:
- Tracks your last 10 completed runs automatically (persisted locally).
- Displays character sprite & costume, Win / Loss status, run duration, defeated boss or killer enemy/hazard icon, and a scrollable chronological grid of all collected items.
- Accurately prioritizes major final bosses (Delirium, The Beast, Mother, Mega Satan, Ultra Greedier, Hush, The Lamb, ???, Satan, Isaac, Mom's Heart) and resolves projectiles/lasers/hazards to their source.
- Supports twin characters (Jacob & Esau) and filters hidden internal collectibles.

COMPATIBILITY (HYBRID ARCHITECTURE):
- With REPENTOGON (Optional): Adds the [H] HISTORY paper note directly onto the Main Menu (Game Menu), uses REPENTOGON GetHistory() for exact pickup order, and supports modded characters & bosses.
- Vanilla Repentance / Repentance+ (No REPENTOGON Required): Toggle the Run History overlay anytime during a run with [H] or [F3], featuring real-time chronological item pickup tracking and automatic gameplay input blocking while open.

CONTROLS & CUSTOMIZATION:
- Open / Close History: [H] (or LT on controller in Main Menu; [H] or [F3] in-game)
- Navigate Runs: [Up] / [Down]
- Scroll Collected Items: [Left] / [Right]
- Close / Return: [Esc] or Back button
- Rebind Hotkey: Press [F2] inside the History panel, configure under Mod Config Menu (Run History -> Controls), or run `history_key <KEY>` in the debug console.
